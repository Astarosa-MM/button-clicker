# Clicker

A simple, responsive button click counter. Click the button to count, or reset to start over. Counts stay through page refreshes in the current tab using sessionStorage and end when the tab closes. Keyboard users can focus the button and press Enter or Space.

## Preview locally

Open `index.html` in your browser, or run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit http://127.0.0.1:8000. No build step or installation required. Built with HTML, CSS, and JavaScript. Google Fonts are optional; system fonts provide an offline fallback.
